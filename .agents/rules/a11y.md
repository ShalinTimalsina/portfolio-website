# Accessibility Rules

All a11y decisions follow [HCI-A11Y.md](../../docs/HCI-A11Y.md). Key rules:
- WCAG 2.2 AA compliance. Contrast ≥ 4.5:1 for text.
- Every interactive element: visible focus ring, 44×44px min touch target.
- All images have descriptive `alt` text. Decorative images use `alt=""`.
- Keyboard navigation for every flow. Tab order = visual order.
- `prefers-reduced-motion` respected everywhere.
- axe-core: zero violations.
