# Content Rules

All copy decisions follow [CONTENT.md](../../docs/CONTENT.md). Key rules:
- Never fabricate facts. Use `TODO(Shalin): confirm` for unverified claims.
- Skills use honest tiers: Daily / Working / Learning.
- No banned phrases ("passionate about", "results-driven", etc.).
- Active voice, first person, concise.
- CTAs are specific ("Read the case study" not "Learn more").
