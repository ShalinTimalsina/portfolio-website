# Design Rules

All visual decisions follow [DESIGN.md](../../docs/DESIGN.md). Key rules:
- ONE accent color (`--accent`). No secondary accents.
- Dark-first. Light mode is not an afterthought.
- No banned fonts (Inter, Roboto, Arial, Open Sans).
- Cards use nested "double-bezel" architecture.
- No items from the banned cheap-AI patterns list.
- Icons: Phosphor Light only. No thick-stroked Lucide defaults.
