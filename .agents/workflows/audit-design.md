# Workflow: Audit Design

1. Read [DESIGN.md](../../docs/DESIGN.md)
2. Capture screenshot of target UI
3. Invoke `design-taste-frontend` and `high-end-visual-design` to critique
4. Check for banned patterns (purple gradients, centered everything, generic fonts)
5. Verify tokens (spacing base-8, nested card architecture)
6. Implement fixes
7. Re-test against checklist
